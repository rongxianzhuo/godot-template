## Bev's recommended import settings

Per Bev's ART_SPEC.md:

| Setting        | Value                  | Rationale                                                 |
|----------------|------------------------|-----------------------------------------------------------|
| `compress/mode`| `VRAM Compressed`      | ETC2 / ASTC on Android; saves 60–80% of texture RAM       |
| `compress/hdr_compression`| `Disabled`   | UI art is 8-bit, not HDR                                  |
| `mipmaps/generate` | `false`            | UI sprites don't need mipmaps; saves ~33% of VRAM         |
| `filter`       | `Linear` (NOT Nearest) | Bev's art has hard pixel edges that look better smoothed |
| `process/alpha` | `Premultiplied`       | Cleaner alpha edge blending when overlaid                 |

These live in each `*.png.import` sidecar (auto-generated by `godot --import`).
Re-run `godot --headless --import` after Bev changes them in the editor.

## When Bev ships new art

1. Drop the new PNG into `assets/gems/`, `assets/ui/`, or `assets/backgrounds/`.
2. Run `godot --headless --import` (Robin does this after pull).
3. If a new `GemType` is added, update both:
   - `Board.cs` enum (add value, keep index order)
   - `SpritePaths.cs` map (add path)
4. Push PNG + `.png.import` together so other agents don't need to re-import.

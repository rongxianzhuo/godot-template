## 📊 8 个候选 polish items

### 🔴 Top 3 (D+22-D+30, must-have)

#### 1. App Bundle per-language split (priority #1)

| Field | Value |
|-------|-------|
| **Estimated effort** | 0.5-1 day |
| **Source** | release notes §4 v1.2 polish backlog #1 |
| **Bundle savings** | 19-25%（per-locale APK 减小） |
| **Dependencies** | Android App Bundle `.aab` export config (Godot 4.7 Android export) |
| **Trade-offs** | ✅ 节省 bundle 19-25%；❌ Google Play Console 配置稍复杂 |
| **Implementation** | Godot export preset → Android → "Split into APKs by language" enabled；CMake build option |
| **Acceptance** | Google Play Console `Bundle Explorer` 显示 per-language split；en-only APK < 8 MB；full APK 8.42 MB |

**Why #1**: 节省 19-25% bundle size 是最大性价比 polish item（投入 0.5-1 天，节省 1.5-2 MB = ~20%）。

#### 2. Per-theme-type TTF overrides (priority #2)

| Field | Value |
|-------|-------|
| **Estimated effort** | 1 day |
| **Source** | v1.1 deviation note (release notes §2) |
| **Per-theme differentiation** | Forest = serif; Desert = italic; Ocean = sans |
| **Dependencies** | TTF subsets; ThemeBuilder.cs (D+18 Jacob done) |
| **Trade-offs** | ✅ 3 主题视觉差异化；❌ 需要 3 font family（+200 KB）|
| **Implementation** | `assets/fonts/{Forest,Desert,Ocean}/` 子目录；ThemeBuilder.cs 按 `GameState.Level/20+1` 选 theme；3 fonts subset |
| **Acceptance** | Forest 主题进 Forest theme font（serif 候选：Lora 或 Source Serif Pro）；Desert italic（Pacifico 或 Caveat）；Ocean sans（已用 Nunito Regular） |

**Why #2**: 3 主题已有 (Forest 1-20 / Desert 21-40 / Ocean 41-60)，但字体 uniform。Per-theme TTF 让主题视觉差异化。

#### 3. Splash i18n (priority #3)

| Field | Value |
|-------|-------|
| **Estimated effort** | 0.25 day |
| **Source** | i18n caveat #1 (release notes §3 v1.1 known issue) |
| **Issue** | v1.1 splash subtitle 仍是 hardcoded "60 Levels · 3 Themes" |
| **Dependencies** | LocaleManager.cs (Jacob D+18 已 done); splash B-v3 scene (Jacob D+17 已 done) |
| **Trade-offs** | ✅ i18n consistency 一致；❌ 需要 +3 string 翻译（en/es/pt-BR）|
| **Implementation** | splash B-v3 subtitle = `Tr("splash.subtitle", "60 Levels · 3 Themes")`；es.po/pt-BR.po 加 3 string（"¡60 Niveles · 3 Temas!" / "60 Níveis · 3 Temas!"）|
| **Acceptance** | 切换 es 显示 "¡60 Niveles · 3 Temas!"；切换 en 还原；切换 pt-BR 显示 "60 Níveis · 3 Temas!" |

**Why #3**: v1.1 i18n 已经做了 9 个 string，但 splash 是 first-impression 没翻译。低成本高 ROI。

### 🟡 Medium priority (D+30-D+45, nice-to-have)

#### 4. Language picker + Settings 屏幕 (i18n caveat #4)

| Field | Value |
|-------|-------|
| **Estimated effort** | 1-2 days |
| **Source** | i18n caveat #4 (v1.1 known issue: 没有 language picker UI) |
| **Issue** | v1.1 i18n 是系统 default locale，无手动切换 |
| **Dependencies** | LocaleManager.cs (done); Settings screen (新增) |
| **Trade-offs** | ✅ 用户可手动切换；❌ +1 screen + 2 PO files |
| **Implementation** | 新增 `src/Features/Settings/SettingsScreen.cs` + `SettingsScreenArgs`；LanguagePicker widget = 3 buttons (en/es/pt-BR)；调用 `LocaleManager.SetLocaleAsync()` |
| **Acceptance** | Settings 屏幕可手动切换语言；切换后实时更新（不需重启）；selection 持久化到 `user://settings.cfg` |

**Why medium**: 不是 must-have（系统 locale 兼容大部分用户），但用户反馈明显。

#### 5. i18n key naming 优化 (dedup conflict)

| Field | Value |
|-------|-------|
| **Estimated effort** | 0.5 day |
| **Source** | i18n caveat #2 (v1.1 known issue: `hud.score` / `hud.score_2` 冲突) |
| **Issue** | v1.1 抽取脚本 normalized strings 但 dedup 时丢 context |
| **Dependencies** | i18n extract script (D+13 done) |
| **Trade-offs** | ✅ cleaner i18n keys；❌ 需要重抽 + 重翻译 |
| **Implementation** | 脚本加 context (file:line); rename keys: `hud.score` → `hud.score_main` + `hud.score_bonus`; auto re-translate |
| **Acceptance** | 0 dedup conflict；每个 string 有 file:line context |

**Why medium**: v1.1 9 个 strings 没冲突，但 v1.2 加 50-70 string 后会冲突。提前优化省 token。

#### 6. 4 P1 sprite AI 重制（如 founder 反馈）

| Field | Value |
|-------|-------|
| **Estimated effort** | 1 day (if triggered) |
| **Source** | release notes §4 v1.2 polish #6 |
| **Trigger** | Founder Google Play 用户反馈"btn_play/locked/heart/coin 不够 cosmic" |
| **Dependencies** | polish 6 (v1.1 done) |
| **Trade-offs** | ✅ 4 sprites 全 cosmic；❌ +150 KB（polish 6 已 +206 KB）|
| **Implementation** | AI re-gen 4 sprites with cosmic theme (per polish 6 方法); coin sprite 5v (5 变体 pick best) |
| **Acceptance** | 4 sprites 全 cosmic；6 gem family 视觉协调 |

**Why medium (contingent)**: 只有 founder 反馈才触发。polish 6 已 done 3/4，polish 7 trigger 不大。

#### 8. Sound effects + BGM

| Field | Value |
|-------|-------|

## 🎯 v1.2 scope 推荐

### Option A: Minimal (1 周)

| # | Item | Days |
|---|------|------|

| 2 | Per-theme TTF | 1 |
| 3 | Splash i18n | 0.25 |

### Option B: Standard (2 周)

| # | Item | Days |
|---|------|------|
| 1-3 | (Option A 全部) | 1.75-2.25 |

### Option C: Full (3+ 周)

| # | Item | Days |
|---|------|------|
| 1-6 | (Option B 全部) | 4.25-5.75 |
| 7 | Level select grid | 3-5 |
| 8 | Sound + BGM | 2-3 |
| **Total** | | **9.25-13.75 days** |

**Trade-off**: 完整游戏体验，但 2-3 周是大 polish cycle。

### 🟢 我的推荐

**Option B (Standard 2 周)** — Top 3 必须 + Language picker + i18n naming + 4 sprite contingent。
**Why**:
- Option A 节省 bundle + 视觉 + i18n 一致，但用户无法手动切换语言（用户体验缺口）
- Option C 加 Level select + Sound 是大功能，应该独立 release (v1.3 / v2.0)
- Option B 适中 (1.25-2.25 周) 与 v1.1 polish cycle (D+10-D+21, 11 天) 类似

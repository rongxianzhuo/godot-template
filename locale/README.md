**翻译方法论（D+13）**：

- ✅ Latin American Spanish (informal "tú" form: "¡Has ganado!")
- ✅ Brazilian Portuguese (informal "você" form: "Você ganhou!")

## 使用流程

### 1. 抽取（v1.1 实施后）

每次 C# 代码加新 hardcoded UI 字符串后：

```bash
python3 scripts/extract_i18n_strings.py
```

会扫描 `src/**/*.cs` 并重写 `locale/en.po`。

### 2. 翻译

**手工方式**：
1. 用 POEdit / Weblate 编辑 `locale/es.po` / `locale/pt-BR.po`
2. 填入 msgstr
3. 保存

**DeepL Pro 自动翻译 + human review**：
1. DeepL Pro API 翻译 `locale/en.po` → `locale/es.po`
2. Native speaker review
3. 术语表统一（glossary 维护在 `locale/glossary.md`）
4. 提交到 main branch

### 3. Godot 加载（v1.1 实施时 Jacob 写）

```csharp
// src/Core/LocaleManager.cs (新建)
public static class LocaleManager {
    public static void LoadLocale(string lang) {
        var translation = new Translation();
        translation.LoadFromFile($"res://locale/{lang}.po");
        TranslationServer.AddTranslation(translation);
        TranslationServer.SetLocale(lang);
    }
}

// 在 _Ready() 调用
LocaleManager.LoadLocale("en");  // 默认
```

### 4. UI 替换（v1.1 实施时）

```csharp
// v1.0 (current)
titleLabel.Text = "Magic Match";

// v1.1 (after i18n integration)
titleLabel.Text = Tr("brand.magic_match");
// 或
titleLabel.Text = TranslationServer.Translate("brand.magic_match");
```

### 5. CI 验证（GitHub Actions）

```yaml
# .github/workflows/validate-i18n.yml
- name: Validate PO files
  run: |
    for lang in en es pt-BR; do
      msgfmt --check locale/$lang.po -o /dev/null
    done
    # 100% msgid coverage check
    python scripts/validate_po_coverage.py
```
